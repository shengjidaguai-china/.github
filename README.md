## 你能得到什么

- **学习与成长**：和不同领域的伙伴交流，在真实项目中学习和提升。
- **真实项目经验**：参与开源项目，从想法到落地，积累真正的实战经历。
- **作品与履历**：优秀贡献获得项目署名、GitHub Contribution，沉淀属于自己的公开作品。
- **免费课程共创**：参与社区免费课程的设计、制作与共建，并获得对应署名。
- **项目曝光**：优秀成员项目和作品，有机会获得社群主理人视频讲解、推荐和展示。
- **链接更多伙伴**：认识开发者、设计师、产品、AI 创作者以及不同领域的实践者。
- **更多机会**：获得项目合作、比赛组队、工作、创业和商业合作等可能性。

## 你需要付出什么

- 愿意分享自己的知识、经验和踩过的坑。
- 愿意参与项目、课程和社区内容共建。
- 用代码、设计、产品、测试、内容等方式贡献自己的力量。
- 在自己能力范围内帮助其他成员。
- 尊重原创、贡献者和开源协议。
- 保持创造，持续学习，也愿意带着别人一起成长。

## 如何参与

每个项目独立维护自己的贡献规则、署名和贡献者页面。

1. 从当前共建项目中选择一个真正感兴趣的项目；
2. 阅读项目自己的 README、Issue、贡献指南和许可证；
3. 先确认真实问题，再提交代码、测试、设计、产品方案或其他可以落地的作品；
4. 由对应项目维护者 Review、决定是否采用并处理署名。

社群优先组织需要真实判断、验证和落地的项目工作。详细说明见[如何参与项目](./CONTRIBUTING.md)。

[查看升级打怪开源社群资金透明账本](https://wcng30x0nvef.feishu.cn/base/KP9UbfeesaatN0sKe7Tc9JDDnFc?table=tblGvMJoDoqu5Xeb&view=vewnhIL5Fp)

- 其他推动开放、创造、共建与成长的社区建设资金。

项目状态每月核对一次，公开展示默认分支、最后推送时间和许可证识别结果。

## 最后想说

这个时代，永远不要害怕开源，不要害怕共享，也不要因为担心被借鉴、被模仿，就把自己的作品藏起来。

“教会徒弟，饿死师傅”的时代正在过去。

AI 正在让知识获取的成本越来越低，很多曾经稀缺的知识和技能也在逐渐普及。

未来真正拉开人与人差距的，会越来越多地来自你的认知、判断力、创造力、影响力，以及把事情真正做出来的能力。

欢迎大家来到升级打怪开源社群，一起学习，一起创造，一起共建，一起升级打怪，共同进步。
