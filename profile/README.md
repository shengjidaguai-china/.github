## 🧭 如何参与

你可以从适合自己的方式开始：

1. **学习新手教程**

   查看社区资料，参加督促共学，学习如何借助 AI 完成自己的第一个项目。

2. **参与开源项目**

   选择感兴趣的项目，反馈问题或参与代码、产品、设计、测试、文档和内容共建。

3. **成为项目维护者**

   持续参与一个项目，负责处理问题、审核贡献、完善内容和推动项目更新。

4. **发起自己的项目**

   把自己的想法或已有项目提交给社区，经过审核后加入社区开放共建项目。

5. **参与社区建设**

   共创新手教程、帮助新人、组织活动、推广项目，或者为社区提供其他支持。
